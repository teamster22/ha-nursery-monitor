# Build journal

Working notes from building this. **Not instructions.** The docs one directory up are what you build from.

These are published because the reasoning behind a decision is often more useful than the decision, and because a repo that only shows the finished answer teaches nothing. They are also messy: they use task IDs from my own kanban board, cross-reference sections that only resolve inside a single document, and argue with a version of the design that no longer exists.

| File | What it is | Status |
|---|---|---|
| [tablet-build-notes.md](tablet-build-notes.md) | The original build proposal for the parent unit. Latency budget, Fully Kiosk settings walkthrough, risk table. | Superseded by [../tablet-build.md](../tablet-build.md) |
| [sensor-selection.md](sensor-selection.md) | The first brief on what to sense. Includes a full load-cell BOM and mechanical build. | **Specs hardware that was never built.** Do not build from it. |
| [layout-research.md](layout-research.md) | What commercial baby monitors put on screen, and three layout options. Option A shipped. | Design exploration, pre-build |

If you're implementing this, close this directory and go back to [../../README.md](../../README.md).
